# 用户画像与自适应沟通偏好档案 (`USER_PROFILE.md`)

> [!NOTE]
> **档案定位与「内外严格隔离」铁律**：
> 1. **首次唤醒破冰机制**：当下方 `Onboarding_Completed` 状态为 `false` 时，AI 在首次与用户开启项目对话时，必须先调用 `ask_question` 弹出 **1 次「三合一破冰问卷」**（询问语言偏好、编程段位 `L0/L1/L2`、输出版式偏好），写入本文件并将状态设为 `true`。一旦设为 `true`，后续所有跨窗口对话自动读取本档案，**严禁重复打扰询问**！
> 2. **对外千人千面，对内顶级工业工作集群（Strict Internal/External Separation）**：
>    - **【对内研发层（绝对禁止降级）】**：无论用户是 `L0 零基础小白` 还是 `L2 专业极客`，AI 内部的意图潜台词补齐、子代理并发调研、主代理四步交叉审查、乐高模块化代码质量、知识图谱与向量召回、120 项防漏自检、6 道真机门禁验收，**永远 100% 执行最严苛的工业级标准**！绝不允许因为用户是小白而在内部逻辑或代码质量上偷工减料！
>    - **【对外沟通层（按等级精准适配 + 按需切换）】**：在每次最终向用户输出回答前，严格按照下方 `Proficiency_Level` 登记的等级输出对应版本（他是什么等级就给他看什么等级的版本）；如果用户在对话中临时要求*“给我看看专业版 / 大白话版”*，立即按需输出对应版本！

## 二、 三大编程段位的对外输出标准规范（Output Adaptation Matrix）

| 用户段位 (`Proficiency_Level`) | 默认对外输出版本与语言风格 | 当用户说“给我看看另一个版本”时的按需展开内容 |
| :--- | :--- | :--- |
| **`L0_BEGINNER`<br>（零基础小白 / 产品主理人）** | **【🗣️ 纯享大白话人话版】**：<br>1. 全程使用生活化比喻（如“餐厅前厅/后厨/账本/时光机”），零底层黑话；<br>2. 直接说明：**改好了什么效果、你现在怎么点/怎么用、我已经帮你跑通了哪些真机体检**；<br>3. 遇到决策只给带 `(Recommended)` 的傻瓜式选项。 | 若用户要求*“看看正常/专业版”*：立即追加输出 **【🛠️ 正常专业工程版】**（含架构变更、精确文件与行号链接、AST/门禁实测指标、根因剖析）。 |
| **`L1_INTERMEDIATE`<br>（懂概念的进阶创作者）** | **【🌓 大白话核心结论 + 关键工程锚点版】**：<br>先用大白话讲清业务流转逻辑与验证结果，再附上精简的改动文件链接表与核心原理解释（遇到生僻术语自动括号附上人话解释）。 | 支持随时要求展开完整的底层代码实现细节或退回纯大白话摘要。 |

## 三、 首次启动「三合一破冰问卷」标准 `ask_question` 模板

```json
  "questions": [
    {
      "question": "【首次启动·10秒专属沟通定制】为了让我后续给你的每次汇报都最合你胃口（注：无论选哪项，我内部写代码和跑测试永远执行最高工业级标准！），请选择你的编程段位与默认汇报风格：",
      "options": [
        "(Recommended) 中文母语 + L0零基础小白模式（默认只看通俗大白话版，需要看专业技术版时我随时喊你展开）",
        "中文母语 + 双版本同屏模式（每次回答同时给我展示【大白话人话版】和【正常专业工程版】对照看）",
        "中英双语 + L1进阶模式（用通俗语言讲原理，同时保留核心技术词汇与改动文件链接）",
        "专业极客模式 L2（直接输出硬核工程实现、代码行号与门禁数据，不啰嗦基础概念）"
      ],
      "is_multi_select": false
    }
  ]
}
```
